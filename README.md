# A Place to Think

A quiet personal thinking journal for capturing thoughts, emotions, ideas and unanswered questions.

## Current version

Version 1 is a static website with local browser storage.

- Journal
- Ideas
- Questions
- Topics
- New Thought editor
- Responsive design
- Warm ivory + muted yellow visual system

### Important

Journal entries are stored in the browser's `localStorage`. They are not synchronized across devices and are not a secure private database yet.

The next version can add authentication and a database.
